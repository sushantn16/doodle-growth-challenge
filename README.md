# Poll dashboard with an A/B-tested Upgrade button

Solution to the Doodle [Growth Fullstack Engineer challenge](https://github.com/DoodleScheduling/hiring-challenges/tree/master/growth-fullstack-engineer).

## Start the app

Needs Java 21 and Node 20.19+ (or 22.12+).

```sh
# terminal 1: backend on http://localhost:8080
cd backend && ./gradlew bootRun

# terminal 2: frontend on http://localhost:5173
cd frontend && npm install && npm run dev
```
